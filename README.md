# LinkVideo.Tools

Рабочая тестовая версия **0.8** — утилита для Windows, дополняющая локальный LinkVideo.Server.

## Функции
- Поиск записей Nimble по индексу и отображение реальных временных интервалов и пропусков
- Экспорт локальных видеозаписей в MP4 через FFmpeg
- Проверка процессов LinkVideo.Server и Nimble, настраиваемый мониторинг службы Nimble
- Экспериментальный запуск **штатной синхронизации** через локальный API LinkVideo.Server
- Диагностика по журналу каждые 3 секунды: запрос интервалов, получение upload-token, ошибки JSON, попытки передачи .dat и индекса
- Отмена только ожидания локального ответа (до 2 минут), последующее наблюдение за логами в течение 3 минут

## Важно о выгрузке
Текущий вызов `GET /api/sync-with-dat?start_dt=...&end_dt=...` запускает синхронизацию архива для всех настроенных камер за период. Это **не принудительная перезапись** уже существующей облачной записи. HTTP 200 подтверждает выполнение запроса локального API, **не успешную отправку архива**. Запускать только на своей тестовой системе до полноценной проверки.

Автоматический перезапуск Nimble отключён по умолчанию. Утилита не изменяет локальные .dat и индексы.

## Сборка
Требуется Go 1.23+:
```powershell
go test ./...
go vet ./...
$env:GOOS="windows"; $env:GOARCH="amd64"; $env:CGO_ENABLED="0"
go build -ldflags="-H windowsgui -s -w" -o LinkVideo.Tools.exe .
```
Или `build_windows.cmd`. Для экспорта MP4 необходим FFmpeg. Исходная инструкция: [README_RU.md](README_RU.md).

## Дальнейшее развитие
Подтверждение реальной выгрузки, независимый модуль принудительной загрузки только после проверки протокола, оформление в стиле LinkVideo.Helper, диагностика и поиск камер в локальной сети.

В репозиторий **не входят** проприетарные исполняемые файлы LinkVideo.Server, клиентские видеозаписи, конфигурации, RTSP-пароли и ключи.
