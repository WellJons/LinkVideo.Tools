# LinkVideo.Tools

Инструменты диагностики и обслуживания локального LinkVideo.Server (Windows).

## Текущий этап

Тестовая версия **0.7**: локальный архив Nimble, интервалы записи, экспорт MP4, мониторинг Nimble и экспериментальный запуск штатной синхронизации через локальный API LinkVideo.Server 1.1.12.

Полный исходный код этой тестовой версии пока распространяется в ZIP вместе со сборкой; миграция исходников в этот репозиторий — следующий этап. Этот README не означает, что приложение уже опубликовано в репозитории.

## Ручная выгрузка

Для тестовой версии используется локальный API LinkVideo.Server:
- `POST http://127.0.0.1:48518/api/auth/login` — локальный вход, токен остаётся только в памяти
- `GET http://127.0.0.1:48518/api/sync-with-dat?start_dt=<unix>&end_dt=<unix>` — штатный запуск синхронизации

**Внимание:** endpoint относится ко всем настроенным камерам за период. HTTP 200 от локального API не означает успешную передачу в облако и не гарантирует принудительной перезаписи уже существующего архива. Тестируйте только на своей тестовой установке, сверяйте с журналом и облачной шкалой.

## Планы

Диагностика камер и потоков, настройка сетевых камер и их обнаружение в LAN, интерфейс в стиле LinkVideo.Helper. Автоматический перезапуск Nimble должен оставаться выключенным до проверки на реальной системе.

Секреты из локальных конфигураций и RTSP-ссылок никогда не коммитить.
